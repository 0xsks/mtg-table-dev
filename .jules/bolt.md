## 2024-10-03 - Optimizing tightly coupled arrays loops and filters
**Learning:** In a highly iterated loop spanning over 36k+ elements, closures and array functional methods like `Array.some` and `Array.every` introduce a substantial overhead because an anonymous function callback acts as a boundary creating context closures and executing in every iteration. Similarly, operations generating new string permutations iteratively instead of evaluating them upfront introduce large penalties.
**Action:** Lift static query preparations outside of array scans in Node, specifically regex parses or mapping. Substitute array functional methods like `.some()` or `.every()` with standard index-based `for` loops within the tightly executed search segments when executing repeatedly without yielding (especially iterating an array inside an iterated array).
