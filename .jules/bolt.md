## 2025-10-12 - Functional Array Methods and String Regex in Hot Loops
**Learning:** In a codebase containing large in-memory arrays like `searchCards`, using JavaScript functional methods like `.some()`, `.every()`, or `.map()` along with regex evaluations (`.replace()`) and string operations (`Number()` conversions or `.split()`) inside a loop iterating over 36,000+ items creates significant GC pressure and execution overhead due to closures and string allocations.
**Action:** When filtering over massive in-memory arrays, ALWAYS pre-parse complex filter constraints (such as mapping comma-separated query strings into boolean/object-based criteria arrays) BEFORE the hot loop. Also replace closure-based methods like `.some()` or `.every()` with standard `for` loops within the iteration to bypass function invocation and scope allocation costs.
